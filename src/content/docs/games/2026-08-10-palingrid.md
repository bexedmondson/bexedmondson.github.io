## Game Description

Make words in a grid and maximise your score with a different set of letters each day! Reach the day's goals, or take on the challenge of topping the leaderboards. Easy to play, hard to master!

## My contributions

This is my first fully released solo game! I built it using GDScript with Godot 4.7. The only part I didn't do was come up with the original game design - that was my mum's idea! You can read more about how this game came to be [here](## "coming soon").

I also wrote a predictive model using machine learning in Python to generate realistic goals for each day's letter set. That was a really interesting project that you can read about [here](## "coming soon").

## Future

I'm not yet done with this project, and I want to do a lot of post-release updates to flesh out some of the gameplay and make it more user friendly. Watch this space for features like:
- cross-device player accounts
- achievements
- rotate grid and shuffle dock buttons
- screen reader support
- free letter choice mode and corresponding all-time leaderboard
- leaderboard history
